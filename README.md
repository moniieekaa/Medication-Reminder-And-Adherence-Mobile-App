# Medication Reminder & Adherence App

A simple and effective Android application that allows users to schedule their medication with specific tablet names, dosage, and time. The app sends timely alerts and notifications to ensure adherence and consistency.

## Features

- Schedule medications by name, dosage, and time
- Receive timely notification alerts
- Easy-to-use and clean user interface
- Built for daily medication adherence
